Welfare

What the city lost to conflict. Bribes and taxes only move money between players, so they cancel out. The best feasible day is worth 12: no crime, no inspections or audits, both gangs respecting.

Forecast accuracy

Each player's daily forecasts, scored only on events its own moves don't decide. Brier score: 0 is perfect, 0.25 is a coin toss. Skill: 1 is perfect, 0 is no better than knowing each event's base rate in this run, below 0 is worse.
