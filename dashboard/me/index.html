My keys

Checking who you are...

Each key is encrypted as soon as it reaches the server. Nobody can read it back, the other participant included: this page only shows the last 4 characters. On your game days, your keys pay; if you have no key for a provider, the other participant's covers it.

Use a key made just for Tidewall, with a monthly spending limit set in the provider's console. Test asks the provider to list its models: free, and it proves the key works, though it can't show how much credit is left.
